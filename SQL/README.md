# SQL — практикум по базам данных

Набор проектов по SQL и работе с реляционными базами данных (PostgreSQL). Это самостоятельный трек, в котором каждый блок — серия практических задач нарастающей сложности: от первых `SELECT` до моделирования хранилища данных и управления параллельными транзакциями. В каждом блоке решения лежат в `src/exNN/*.sql`.

Трек построен вокруг общей модели данных пиццерии (таблицы `person`, `menu`, `pizzeria`, `person_order`, `person_visits`), поэтому задачи логически связаны между собой и усложняются от блока к блоку.

## Краткая выжимка по каждому проекту

### SQLB1 — Основы баз данных
Первые шаги: простые выборки с фильтрацией и сортировкой.
- Фильтрация по адресу и полу (`WHERE`, `BETWEEN`, `DISTINCT`).
- Формирование строк через `CONCAT`, преобразование типов.
- Логика ветвления `CASE` для группировки возрастов по интервалам.
- Подзапросы в `SELECT`, работа с чётными/нечётными `id`.

### SQLB2 — Выборка данных (UNION, JOIN)
Наборный модуль по комбинированию данных из нескольких таблиц.
- `UNION ALL`, `INTERSECT`, `EXCEPT` для объединения выборок.
- `CROSS JOIN` — полное декартово произведение.
- `NATURAL JOIN` и классические `JOIN ... ON` по нескольким таблицам.
- Подзапросы в `WHERE`, `IN`/`NOT IN`, `EXISTS`/`NOT EXISTS`.

### SQLB3 — Продвинутая выборка (CTE, generate_series)
Усложнённые запросы с генерацией данных и общими табличными выражениями.
- `generate_series` для построения календарной сетки и поиска «пропущенных» дат.
- `COALESCE` для заполнения пропусков при `LEFT JOIN`.
- `WITH` (CTE) для декомпозиции сложных выборок.
- Многотабличные `JOIN` с условиями по нескольким пиццам и адресам.
- Само-соединения для поиска людей с общим адресом.

### SQLB4 — DML: изменение данных
Создание, изменение и удаление строк — база для наполнения БД.
- Анализ «неиспользуемых» позиций меню через `NOT EXISTS`.
- Вставка строк с вычислением следующего `id` (`SELECT MAX(id)+1`).
- Массовая вставка через `INSERT ... SELECT`.
- `UPDATE` с процентным пересчётом цены, `DELETE` с условием по дате.

### SQLB5 — Представления (VIEW)
Абстракция запросов в переиспользуемые объекты схемы.
- Простые `VIEW` для мужчин/женщин, календарной сетки дат.
- Вычисление пропущенных дат через `EXCEPT` между представлениями.
- `MATERIALIZED VIEW` для тяжёлого запроса по визитам.
- `v_symmetric_union` — симметричное объединение визитов.
- Скидки через представление с пересчётом цены (`ROUND`).

### SQLB6 — Графы и рекурсивные CTE (задача коммивояжёра)
Самая содержательная задача трека — поиск маршрутов по взвешенному графу.
- Таблица `graph` с рёбрами «город — город — стоимость».
- `WITH RECURSIVE` строит все обходы из точки `a` по 4 городам.
- `UNION ALL` расширяет маршрут, `ARRAY` отслеживает посещённые города.
- Итог: минимальный и максимальный по стоимости полный маршрут.

```sql
WITH RECURSIVE tsp AS (
    SELECT ARRAY['a','b']::varchar[] AS tour, 'b' AS last_city, cost, 2 AS visited
    FROM graph WHERE point1 = 'a'
    UNION ALL
    SELECT tsp.tour || n.point2, n.point2, tsp.cost + n.cost, tsp.visited + 1
    FROM tsp JOIN graph n ON n.point1 = tsp.last_city
    WHERE NOT (n.point2 = ANY(tsp.tour)) AND tsp.visited < 4
)
SELECT * FROM tsp;
```

### SQLB7 — Индексы и оптимизация
Производительность запросов через индексы и анализ планов.
- Создание индексов на колонки-ключи `JOIN` (`idx_menu_pizzeria_id` и др.).
- `EXPLAIN ANALYZE` с `SET enable_seqscan = OFF` для оценки работы индексов.
- Индекс по функции `UPPER(name)`, составные и уникальные индексы.
- Частичный индекс с `WHERE order_date = '2022-01-01'`.
- Оконная функция `max(rating) OVER (PARTITION BY ...)` в аналитическом запросе.

### SQLB8 — Интеграция данных (скидки)
Построение новой сущности из анализа существующих заказов.
- Создание таблицы `person_discounts` с внешними ключами на `person` и `pizzeria`.
- Заполнение через `INSERT ... SELECT` с оконным `ROW_NUMBER()` и `CASE`.
- Правило скидки: 10.5% (1 заказ), 22% (2 заказа), 30% (3+).
- Уникальный индекс на пару `(person_id, pizzeria_id)`.
- Констрейнты `CHECK NOT NULL`, комментарии к таблице и колонкам.
- Автоинкремент через `SEQUENCE` + `SETVAL`.

### SQLB9 — OLAP: агрегации и оконные функции
Аналитические отчёты по посещениям и заказам.
- `GROUP BY` + `HAVING` для отбора групп с количеством > 3.
- Топ ресторанов по числу визитов и заказов, `LIMIT`.
- Комбинирование визитов и заказов через `UNION ALL` с общим «топом».
- `ROUND(AVG(rating))`, агрегаты `MAX`/`MIN` по пиццериям.
- Сравнение вычисленной статистики через `CASE` в `EX09`.

### SQLB10 — Уровни изоляции транзакций
Поведение параллельных транзакций в PostgreSQL (8 сценариев с двумя сессиями).
- Базовые `BEGIN/COMMIT`, видимость изменений до и после коммита.
- Уровни: `READ COMMITTED`, `REPEATABLE READ`, `SERIALIZABLE`.
- Аномалии: изменение данных «незаметно» для другой сессии, «фантомные» строки.
- Сумма агрегатов (`SUM(rating)`) при параллельных `UPDATE`.
- Проверка, когда конфликт записей приводит к ошибке сериализации.

### SQLB11 — Хранимые функции и триггеры
Программируемая логика на стороне БД (PL/pgSQL).
- Аудит изменений таблицы `person` через триггер + `person_audit`.
- Триггеры на `INSERT`/`UPDATE`/`DELETE` с внесением событий `I/U/D`.
- Функции-фильтры `fnc_persons_female/male`, обобщённая с параметром.
- Функция поиска визитов с тремя параметрами по умолчанию.
- `func_minimum(VARIADIC ...)`, рекурсивный расчёт чисел Фибоначчи через CTE.

### SQLB12 — DWH: основы хранилища данных
Проектирование витрин из операционных данных.
- Таблица `user` с пропущенными значениями (`NULL` в name/lastname).
- Таблица `currency` с историей курсов валют по датам.
- Пересчёт валютных сумм в USD с `COALESCE` и подборкой курса.
- Итог: витрина данных, объединяющая пользователей и курсы валют.

## Освоенные навыки

- **Основы SQL** — SELECT, WHERE, ORDER BY, LIMIT, типы данных, `CONCAT`, приведение типов.
- **Фильтрация и логика** — `BETWEEN`, `IN`, `DISTINCT`, `CASE`, `CROSS/NATURAL JOIN`.
- **Комбинирование данных** — `UNION`/`INTERSECT`/`EXCEPT`, коррелированные подзапросы, `EXISTS`.
- **Агрегации и OLAP** — `GROUP BY`, `HAVING`, `COUNT/SUM/AVG/MIN/MAX`, `ROUND`, оконные функции.
- **CTE** — `WITH`, `WITH RECURSIVE` для графов и рекурсивных последовательностей.
- **DML и схема** — `INSERT/UPDATE/DELETE`, внешние ключи, констрейнты, `SEQUENCE`, `COMMENT`.
- **Представления** — `VIEW`, `MATERIALIZED VIEW`, симметричные объединения.
- **Производительность** — индексы, `EXPLAIN ANALYZE`, частичные и составные индексы.
- **Транзакции** — `BEGIN/COMMIT/ROLLBACK`, уровни изоляции, параллельные сессии.
- **Хранимый код** — функции, триггеры, процедуры, `VARIADIC`, рекурсивные функции.
- **DWH** — витрины данных, работа с историей курсов и пропущенными значениями.
